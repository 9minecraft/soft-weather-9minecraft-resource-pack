# Soft Weather — Gentle Rain and Subtle Snowstorms

Soft Weather 9minecraft Resource Pack replaces vanilla rain and snow with faint, gentle precipitation. The pack thins out heavy rain streaks and shrinks thick snowflakes so your view stays clear. You can look across wide landscapes and build your base without screen clutter during stormy weather. It keeps all other textures untouched and works in any standard world.

Softens heavy rain streaks into light, thin drops that do not cover your screen.

## What this build is

An unofficial rebuild of **vectorwing**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Keeping a pack alive across releases is not a copy-paste job: each Minecraft version bumps the pack format and shuffles texture and model paths, so the tree gets re-mapped and every asset re-checked against the version it is built for. Anything the new release dropped is rebuilt rather than left pointing at a path that no longer exists.
